# 轻译 · Float Translate

适用于 Windows 10 / 11 的轻量悬浮翻译工具。Python + Tk 原生窗口，使用 Pillow 处理图片，无 Electron、浏览器内核或本地 OCR 模型。

v0.2.0 新增：四边 / 四角缩放、透明度、鼠标穿透，以及保留结构图的图片译文。

## 运行

双击 `dist/FloatTranslate.exe`，无需安装 Python。源码运行需要带 Tk 的 Python 3.9 或更高版本：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以双击 `start.vbs` 无控制台启动源码版（需要 `pythonw.exe` 在 PATH 中）。

## 首次配置

点击「设置」，填写：

- **接口地址**：例如 `https://你的服务/v1` 或完整的 `https://你的服务/v1/chat/completions`。本机服务可用 `http://127.0.0.1:端口/v1`。
- **模型名称**：服务商提供的准确模型 ID。截图翻译要求该模型以及服务端支持图片输入。
- **API Key**：按服务商要求填写。本地无鉴权服务可留空。

当前支持 OpenAI 兼容的 **Chat Completions** 协议，不直接支持 Anthropic Messages、原生 Gemini 协议或仅支持 Responses 的模型。可以通过兼容网关连接其他服务。图片采用 PNG Base64 `image_url` 输入，格式参考 [OpenAI 官方视觉文档](https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat)。无内置付费账号，无需绑定特定厂商；翻译费用由所配置的服务商收取。

## 使用

- **文字翻译**：选择源语言和目标语言，输入或粘贴文字，点击翻译，或按 `Ctrl+Enter`。
- **截图翻译**：点击「框选截图」，拖动选择矩形区域，松开鼠标自动翻译。选区阶段可按 `Esc` 或右键取消。支持虚拟桌面和多显示器，包括主屏左侧的副屏。
- **图片译文**：默认开启。视觉模型返回每个文字标签的译文与位置，本机在原图对应区域覆盖文字；框、箭头和文字区域以外的像素保持原样。结果在「图片译文 / 原图」页签展示，可切换原图、缩放、拖动查看并导出原始分辨率 PNG。复制按钮复制文字译文。关闭「图片译文」可使用原来的整段文字翻译。
- **语言选择**：源语言可自动识别，也可明确指定。两端均允许直接输入其他语言名称；「⇄」交换指定语言。
- **窗口缩放**：展开时拖动任意边或角改变大小，最小尺寸为 380 × 480 逻辑像素。退出时保存尺寸，兼容 Windows DPI 缩放。
- **透明度**：主窗口「不透明度」滑块在 20%–100% 间实时调节。数值越低，背景越清晰；设置窗口保持不透明，便于配置。退出时保存选择。
- **鼠标穿透**：点击「鼠标穿透」，鼠标即可操作主窗口背后的内容；按 `Ctrl+Alt+P` 解除穿透，或按 `Ctrl+Alt+T` 恢复操作。穿透模式每次启动默认关闭；解除快捷键注册失败时不允许开启穿透，避免无法操作窗口。
- **悬浮条**：点击「−」折叠；点击「□」展开。拖动标题区域移动窗口；点击「×」退出。
- **全局快捷键**：`Ctrl+Alt+A` 框选截图；`Ctrl+Alt+T` 展开并解除穿透；`Ctrl+Alt+P` 切换鼠标穿透。快捷键冲突会在底部提示。
- **重试截图**：截图保留在当前进程内存，点击翻译可再次翻译。输入文字后优先翻译文字；清空文字可重新翻译此前截图。「清空」删除当前截图和文字。
- **取消等待**：翻译期间按 `Esc`，过期结果不会覆盖新的译文。服务端仍可能继续处理并计费。

## 配置与隐私

配置保存在 `%APPDATA%/FloatTranslate/config.json`，API Key 使用 Windows DPAPI 加密，与当前 Windows 用户绑定。截图和图片译文默认只保留在内存；仅在主动选择「导出 PNG」时保存图片。不记录翻译历史。点击翻译、或松开截图选区后，相关内容将发送至你配置的接口。远程接口强制使用 HTTPS；HTTP 仅允许本机地址。程序不收集遥测。

## 图片译文的适用范围

适合底色较平整、文字清晰的结构图、流程图和界面截图。采用「定位 + 文字覆盖」，不重新生成整张结构图。坐标由所配置的视觉模型提供，可能漏识别或偏移；复杂底纹、旋转文字、密集小字和叠在线条上的文字无法保证无损替换。较长译文会自动换行并缩小，极小标签可能需要放大阅读。重要图请对照原图核对，不建议直接作为未经审校的论文配图。

模型需要能够按提示输出带 `regions`、`bbox`（0–1000 归一化坐标）、`source`、`text` 的 JSON；无效或截断结果会提示重试，不会当作有效图片展示。原图始终可查看。图片字体使用系统 Microsoft YaHei；其他字符的支持情况取决于系统字体。

## 开发与打包

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m pip install pyinstaller
.\build.ps1
```

输出为 `dist/FloatTranslate.exe`。打包依赖 PyInstaller，EXE 已包含 Pillow，无需另装 Python。可使用 `.\build.ps1 -OutputDirectory dist/v0.2.0` 指定输出目录。未签名 EXE 可能显示 Windows 发布者提示。

自动测试覆盖实际 GDI 截图、PNG 像素编码、DPAPI 密钥往返、本机模拟 HTTP 服务的文字/图片/坐标请求、错误处理、地址校验、窗口折叠展开与缩放、透明度、设置按钮可见性、选区取消和过期结果隔离；结构图样例验证箭头、节点边框和公式保持像素一致。真实云端接口需要配置用户凭据后验证；识别效果和延迟取决于模型与服务。
